# ⭐ Some of my projects

### 🏥 LLM‑Powered Clinical Insights System (Graduate Research Assistant)

I am currently working on a research entitled “Large Language Model Implementation over Longitudinal Patient Records for Clinical Decision Modeling using Elastic Search and
RAG”. 
A full‑stack AI system that allows clinicians to ask natural‑language questions (e.g., “Show me this patient’s abnormal labs over the last 6 months”) and retrieves data from **longitudinal FHIR‑based EHR data**.

Duties include developing and testing AI/LLM models to achieve accurate patient health
information and predictive health analytics used for preventative care, including deep learning models
aimed at improved early detection of diseases, including disease surveillance.

**What I built:**

- Designed the **backend architecture** using FastAPI, Elasticsearch (BM25 + vector search), and modular ingestion services.  
- Built retrieval pipelines using **MedRAG + LLaMA 3.1 embeddings** for clinically relevant search.  
- Engineered ingestion workflows for **FHIR, ADT, CCDA, ORU** and standardized them using LOINC and schema validation.  
- Created analytics‑ready datasets for **vital‑sign trends, anomaly detection, and source attribution scoring**.  
- Reduced query latency by **~30%** and cut manual data retrieval effort by **~60%**.

**In simple terms:**  
I built a system that lets doctors “talk” to patient records using natural language — fast, accurate, and production‑ready.

### 🤖 Agent‑Guided Token‑Efficient RAG System (Enterprise Policy QA)

A cost‑optimized RAG system that answers policy and compliance questions using an **agentic reasoning layer**, but only when necessary.

**What I built:**

- Developed an **intent‑gating layer** using DistilBERT to decide when the agent should activate.  
- Designed selective memory injection to avoid unnecessary context expansion.  
- Reduced token usage by **up to 40%** while maintaining high answer quality.  
- Improved retrieval performance with a **12% F1 score uplift**.

**In simple terms:**  
I built a smarter RAG system that knows when to think deeply and when to stay lightweight — saving cost without losing accuracy.

An end‑to‑end enterprise BI solution built using **SSIS, SQL Server, and Power BI** to support scalable analytics and automated reporting.
